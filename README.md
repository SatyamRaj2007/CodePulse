# CodePulse

> Track your practice. Measure your progress. Know your readiness.

CodePulse is a DSA practice analytics platform that connects coding-platform profiles and transforms practice history into actionable insights.

## Supported Platforms

- LeetCode
- Codeforces
- HackerRank

## Core Features

- Coding profile integration
- Practice heatmap
- Difficulty analysis
- Topic analysis
- DSA practice readiness score
- Personalized practice recommendations

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- PostgreSQL
- Prisma
